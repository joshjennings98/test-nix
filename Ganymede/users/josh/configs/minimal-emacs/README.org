#+title: minimal-emacs in the Ganymede template

This is the standalone, Nix-managed minimal-emacs.d configuration.
Run =emacs= from a shell or select Emacs in the launcher.

Agent Shell and the complete Org design-review workflow are included. See
=agents.org= for the bindings, package sources, persisted state and tests.
The extension libraries, tests and documentation live in
=configs/minimal-emacs/agent/=.

* Template integration

The repository root exports templates; the Ganymede directory becomes the
root of the installed configuration after =nix flake init -t ...#Ganymede=.
All configuration and test references are relative to that template root.
Nothing depends on the original machine's checkout or Nix store paths.

- =users/josh/nix/minimal-emacs-package.nix= pins minimal-emacs.d, installs Emacs
  packages through Nix, supplies language tools and builds the startup checks.
- =users/josh/nix/minimal-emacs.nix= installs the executable, fonts, skills, desktop entry and
  persistence for editor state.
- =users/josh/nix/home.nix= imports the minimal-emacs module.
- =users/josh/configs/minimal-emacs/*.el= contains the editor settings.
- =users/josh/tests/emacs2-startup.el= exercises the configured editor.

The existing Ganymede flake inputs and lock file supply Emacs and its packages.
The package build retains Nix's native compilation support. This integration
does not change the separate Phobos template or the default editor.

* State and project trust

State is created at runtime in =~/.local/state/emacs2/= (or under
=$XDG_STATE_HOME/emacs2=). Ganymede persists the default location under
=/persist=. No sessions, histories, backups or trusted project choices ship
with the template. If overriding =XDG_STATE_HOME=, adjust persistence to match.

Immediate subdirectories of =~/Documents/= are discovered as projects.
Discovery does not grant trust. Click the modeline's trust indicator or use
=SPC P t= to confirm trust for a project; =SPC P u= revokes it. Choices are
stored in the persisted =trusted-projects= state file.

* Validation

From the Ganymede template or installed configuration root, build the executable
and startup checks without generating hardware files or activating a system:

#+begin_src sh
nix build --impure --expr '
  let
    f = builtins.getFlake ("path:" + toString ./.);
    pkgs = import f.inputs.nixpkgs {
      system = builtins.currentSystem;
      overlays = [
        f.inputs.emacs-overlay.overlays.default
      ];
    };
    emacs = import ./users/josh/nix/minimal-emacs-package.nix { inherit pkgs; };
  in [ emacs emacs.tests.startup emacs.tests.agents ]
' --no-link --print-out-paths
#+end_src

When checking from this repository, run that command inside =Ganymede/=.
The startup checks use a temporary home and do not alter editor state.
The installer's generated hardware and disk configuration remain independent
of this editor setup.
